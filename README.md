 aws-s3-ec2-hands-on-labs

 This project demonstrates hands-on implementation of AWS S3 and EC2 services, focusing on real-world cloud storage and compute use cases. The goal was to        understand how storage, compute, security, and access control work together in AWS.


🏗 Architecture Overview
The architecture involves:
- EC2 instances acting as compute resources
- S3 used as object storage for data and static content
- IAM roles enabling secure interaction between EC2 and S3
- Security Groups ensuring controlled network access
